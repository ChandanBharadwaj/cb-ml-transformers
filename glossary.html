Glossary

Every important term from the course, A–Z, each linking back to the page that teaches it. This list grows as modules are published.

A

Agent (ReAct loop) — an LLM in a Reason→Act→Observe loop: it reasons, emits a tool call, your runtime executes it and feeds the result back as tokens, repeat until a final answer. A for-loop around a model with tools. → Tool Calling & Agents

ANN (approximate nearest neighbor) — trading a sliver of recall for a huge speedup when searching millions of vectors; HNSW is the common algorithm behind vector databases. → RAG Internals

Anisotropy — raw BERT token vectors huddling in a narrow cone, so every pair of sentences scores "similar"; the reason mean-pooled raw BERT retrieves poorly and contrastive fine-tuning exists. → From Tokens to a Sentence Vector

Attention — score a query against every key (dot products), softmax into weights, blend the values: a differentiable, learnable lookup. The core mechanism of modern AI. → Attention Is Born

Autoregressive generation — produce a token, append it, run again: one full model pass per output token. Why LLMs stream. → Decoder, Masking & Generation

B

BM25 — the modern heir of TF-IDF: a lexical, exact-term ranking function; paired with dense vectors in hybrid search to catch part numbers, codes, and rare names embeddings miss. → RAG Internals

Benchmark contamination — test items leaking into training data, so a model memorizes answers it appears to reason toward; the reason to treat any public benchmark number as an upper bound. → LLM Benchmarks & Evaluation

BPE (Byte-Pair Encoding) — build a vocabulary by repeatedly merging the most frequent adjacent pair; frequent words stay whole, everything else spells out of pieces. → Tokenization

Bias — the learned vector added after a layer's matrix multiply (the +b in Wx + b); lets the layer shift space, not just warp it. → Matrices Transform Meaning

Base vs instruct checkpoint — raw pretrained text-continuer vs the same weights SFT'd (+preference-tuned) into an assistant; confusing them is the classic model-hub mistake. → Instruction Tuning (SFT)

Bi-encoder vs cross-encoder — embed the two texts separately and compare cheaply (pre-computable, RAG's engine) vs read them together with full attention (smarter, but one pass per pair). The fundamental retrieval trade-off. → Siamese Networks & SBERT

BIO tagging — B-TYPE / I-TYPE / O labels turning span extraction into per-token classification; the B- prefix keeps adjacent same-type entities apart. → NER as Token Classification

Backpropagation — blame flowing backward through the network, multiplying by each stage's local slope (chain rule), yielding every parameter's gradient in one sweep. → Backpropagation, Intuitively

Batch / mini-batch — the handful of examples processed per training step; its size trades gradient smoothness against memory. → The Training Loop

C

Catastrophic forgetting — aggressive fine-tuning overwriting pretrained competence; the reason recipes whisper "small LR, few epochs, move less". → Transfer Learning & Heads

Chinchilla ratio — compute-optimal training wants ~20 tokens per parameter; modern models deliberately overtrain far past it for cheaper serving. → Scaling Laws & Chinchilla

Chat template — the serialization format (special tokens, role headers) that turns your messages array into the token stream the model was actually trained on. → Instruction Tuning (SFT)

Causal mask — the −∞ staircase in attention scores that blocks looking at future tokens; the one difference between BERT's body and GPT's. → Decoder, Masking & Generation

Chain-of-thought (CoT) — prompting a model to emit intermediate steps; because compute per token is fixed, written steps buy extra forward passes and turn the context window into working memory. → Reasoning & Test-Time Compute

Context window — the maximum tokens a model can attend over at once; finite because attention cost grows as n² and the KV cache grows linearly with it. → Context Windows & the KV Cache

Cross-encoder / reranker — reads query and document together with full attention for a precise relevance score; too slow to run on a whole corpus, so it reranks the bi-encoder's top ~50. → Reranking & Retrieval Quality

Cross-attention — attention where queries come from the decoder and keys/values from the encoder's output; how translation models and Whisper consult their input. → Encoder vs Decoder vs Both

Contrastive learning — training by pulling positive pairs together and pushing negatives apart in embedding space; powers word2vec, sentence-transformers, CLIP, and RAG retrievers. → Negative Sampling

Cross-entropy — the loss −log P(truth): a surprise meter that punishes confident mistakes hardest. What LLMs train on. → Softmax & Cross-Entropy

Cosine similarity — the dot product of two vectors after removing their lengths; measures direction agreement, from −1 to 1. The score behind every vector search. → Dot Product = Similarity

D

DPO (Direct Preference Optimization) — preference tuning collapsed into a simple supervised loss: raise the preferred response's probability vs a frozen reference, no reward model or RL. → RLHF & DPO

Distillation (knowledge distillation) — training a small student to mimic a big teacher's soft outputs (or, in MiniLM's case, its attention patterns) instead of hard labels; how 22M parameters inherit 340M's judgment. → Distillation: The MiniLM Part

Distributional hypothesis — "you shall know a word by the company it keeps": words in similar contexts have similar meanings; the license for learning meaning from raw text. → One-Hot & Why It Fails

Dropout — randomly zeroing activations during training so features can't co-adapt; off at inference. → Optimizers & Regularization

Dimension — one slot in a vector. all-MiniLM's embeddings have 384 of them. → Vectors Are Meaning

Dot product — multiply two vectors slot-by-slot and add it all up; one number measuring agreement. → Dot Product = Similarity

E

Encoder / decoder — the reads-bidirectionally stack (BERT/MiniLM: vectors out) vs the causally-masked stack (GPT: next tokens out); enc-dec combines both via cross-attention. → Encoder vs Decoder vs Both

Epoch — one full pass over the training set; fine-tuning uses a few, LLM pretraining often less than one. → The Training Loop

Embedding — a learned vector that represents meaning, placed so that similar things are near each other. → Vectors Are Meaning

G

GQA (grouped-query attention) — groups of query heads sharing one key/value head, shrinking the KV cache several-fold with little quality loss; why 128k contexts became affordable. → Context Windows & the KV Cache

GGUF / GPTQ / AWQ — quantized-model file formats: GGUF for local CPU/GPU (llama.cpp, Ollama), GPTQ/AWQ for GPU serving via calibration-based 4-bit. → Quantization & the Inference Stack

Grounding check — verifying after generation that every claim is supported by the sources; a safety guardrail against hallucination and injection, and the faithfulness metric in disguise. → Safety, Injection & Guardrails

GLiNER — zero-shot NER by matching: entity-type names enter the encoder with the text, spans and labels meet in one embedding space, a thresholded similarity grid extracts entities. New type = new string. → GLiNER's Architecture

Gradient accumulation / checkpointing — big-batch math on small VRAM (sum micro-batch gradients) / trade ~30% compute for activation memory (recompute in backward). → Training at Scale

Gradient (mini-batch / SGD) — real training estimates the slope on a small random batch instead of the whole dataset: noisier, vastly cheaper, and the noise even helps. → Slopes, Gradients & Learning

Gradient — the slope of the loss in every direction at once; points uphill, so training steps the other way. → Slopes, Gradients & Learning

Gradient descent — repeat: measure the slope, step downhill. The algorithm behind all model training. → Slopes, Gradients & Learning

F

Faithfulness (groundedness) — the fraction of an answer's claims supported by the retrieved context; the direct, measurable counter to hallucination and the key RAG generation metric. → RAG Evaluation

FlashAttention — computes exact attention without materializing the n×n matrix in slow memory, tiling through fast on-chip SRAM; same result, far less memory traffic. → Quantization & the Inference Stack

Function calling / tool calling — the model generates JSON naming a tool and arguments; your runtime parses and executes it, feeding the result back as tokens. The model never executes anything itself. → Tool Calling & Agents

FFN (feed-forward network) — the per-token expand→GELU→compress block after attention; holds ~⅔ of a transformer's parameters and most of its stored facts. → Residuals, LayerNorm & FFN

H

Hallucination — confident, fluent, unsupported output; a structural consequence of the next-token objective rewarding plausibility, not truth. Managed by grounding, not by prompting harder. → Safety, Injection & Guardrails

HNSW — a layered navigable small-world graph: enter at a sparse top layer of long-range "highways", greedily hop toward the query, descend to denser layers; ~log(N) hops to find nearest neighbors. → RAG Internals

Hybrid search — fusing dense-vector retrieval (meaning) with BM25 lexical retrieval (exact terms) to cover each method's blind spot. → RAG Internals

HyDE — embedding an LLM-written hypothetical answer instead of the terse question, since a fake answer sits nearer real documents in vector space. → Reranking & Retrieval Quality

Hard negatives — near-miss non-matches (same topic, wrong answer) deliberately added to contrastive batches; they teach fine distinctions that random negatives never force. → Contrastive Training & MNR Loss

I

In-batch negatives — inside a batch of matching pairs, everyone else's positive doubles as my negative: a batch of 64 yields 63 free negatives per example. Why embedding training loves big batches. → Contrastive Training & MNR Loss

In-context learning — examples in the prompt inducing task behavior with zero weight updates; emerged with GPT-3 scale, powers few-shot prompting and RAG. → GPT & Causal LM

K

KV cache — storing past tokens' key/value vectors so each generated token computes only its own QKV; makes chat fast, but grows ~128 KB/token and is the real reason long context is expensive. → Context Windows & the KV Cache

KV / Q (query, key, value) — a token's three learned roles: what I seek, what I advertise, what I hand over. Attention = softmax(QKᵀ/√d)·V. → Self-Attention: Q, K, V

L

LLM-as-judge — using a strong model to grade open-ended output; works well but carries position, verbosity, and self-preference biases you correct by swapping orders and using a judge from another model family. → LLM Benchmarks & Evaluation

Lost in the middle — the U-shaped recall of long contexts: models remember the start and end well and sag in the middle, so put your best retrieved chunks at the edges. → Context Windows & the KV Cache

LayerNorm — re-center and re-scale each token's vector (then learned γ, β); the thermostat keeping hundreds of residual additions numerically sane. → Residuals, LayerNorm & FFN

LoRA / QLoRA — freeze W, train a thin low-rank bypass B·A added residual-style (~0.5% of params); QLoRA holds the frozen base in 4-bit — 8B fine-tuning on a free GPU. → LoRA, QLoRA & PEFT

Language model — a machine assigning probabilities to the next token given a prefix; every LLM capability is this task in a loop. → Language Modeling & Perplexity

Leakage — test information contaminating training (shared preprocessing stats, duplicates across splits, temporal mixing); the silent killer of honest metrics. → The Training Loop

Logit — a raw pre-softmax score (w·x + b); one per class or vocabulary token at a model's output. → The Neuron

Learning rate — how big each downhill step is. Too big bounces, too small crawls. → Slopes, Gradients & Learning

Loss — a single number scoring how wrong the model currently is; training exists to push it down. → Slopes, Gradients & Learning

M

MCP (Model Context Protocol) — a standard for how tools describe themselves and get called, so a tool written once works with any MCP-speaking agent. Plumbing, not new intelligence. → Tool Calling & Agents

MMLU / GSM8K / HumanEval / Arena — the headline LLM benchmarks: knowledge MCQ / math reasoning / executed-code pass@k / human-preference Elo. Each measures performance on itself, nothing more. → LLM Benchmarks & Evaluation

MLM (masked language modeling) — hide 15% of tokens (with the 80/10/10 twist), predict from both sides; BERT-family pretraining, ancestor of MiniLM and GLiNER. → BERT & Masked LM

Mixed precision — compute in bf16 for speed, keep fp32 master weights for stable updates; why training memory includes two copies of the model. → Training at Scale

MNR loss (MultipleNegativesRankingLoss) — cross-entropy over a batch's in-batch similarity grid: each query must rank its own positive above everyone else's. The loss that trained all-MiniLM. → Contrastive Training & MNR Loss

MRR (mean reciprocal rank) — average of 1/rank of the first relevant result: rank 1 = 1.0, rank 2 = 0.5. The metric for "did the right chunk come first?" → Evaluating & Tuning Embeddings

MTEB — the Massive Text Embedding Benchmark: dozens of retrieval/clustering/classification tasks behind the embedding-model leaderboard; read it by task family, not by the single average. → Evaluating & Tuning Embeddings

Multi-head attention — h parallel attentions in d/h-dim learned subspaces, concatenated and mixed by W_O; several glance patterns for the price of one. → Multi-Head Attention

Matrix — a grid of numbers that transforms vectors; every "layer" of a neural network is one (plus a bend). → Matrices Transform Meaning

N

nDCG (normalized discounted cumulative gain) — graded relevance summed with a log discount by rank, normalized by the ideal ordering; the retrieval metric when relevance isn't just yes/no. → Evaluating & Tuning Embeddings

Negative sampling — replacing the full-vocabulary softmax with "beat k plausible fakes": pull the real pair together, push sampled fakes apart. → Negative Sampling

Neuron — weighted sum + bias + a nonlinear bend; a layer is a matrix of them. → The Neuron

Norm / normalization — a vector's length (√ of summed squares); dividing by it gives a unit vector so only direction carries meaning. MiniLM normalizes its outputs. → Vectors Are Meaning

O

One-hot vector — a vocabulary-sized vector with a single 1; makes every word orthogonal to every other, so similarity is structurally impossible. → One-Hot & Why It Fails

Overfitting — memorizing training data instead of learning patterns; visible as train loss falling while validation loss rises. → The Training Loop

P

Prompt injection — malicious instructions hidden in content the model reads (user input, or retrieved documents — indirect injection); since instructions and data are one token stream, no prompt wording fully prevents it. Design for it. → Safety, Injection & Guardrails

Perplexity — e^loss: the number of tokens a language model effectively hesitates between per step. Lower = better. → Language Modeling & Perplexity

Prefill vs decode — prompt processed in one parallel compute-bound pass, then output generated token-by-token bandwidth-bound; why output tokens cost 3–5× input. → Inference Economics

Pretraining — self-supervised prediction over a curated internet-scale corpus, paid once at $10M+ scale, producing the base everyone adapts. → Pretraining: The Big Idea

Pooling (mean / CLS / max) — collapsing per-token vectors into one sentence vector; all-MiniLM mean-pools then normalizes, per its modules.json. → From Tokens to a Sentence Vector

Positional encoding — the order-stamp added to (or rotated into) token vectors, since attention itself is order-blind: sinusoids, learned rows (the 512 limit), or RoPE. → Embeddings & Positional Encoding

Precision / recall / F1 — "when I flag, am I right?" / "do I find them all?" / their strict harmonic mean. The measurement kit for imbalanced problems. → Measuring Models

Parameter — one learned number inside a model. "7B model" = seven billion of these. → Matrices Transform Meaning

Q

Quantization — storing weights with fewer bits (int8, int4) by snapping each to a coarser number line; ~4× smaller and faster to stream at ~1–3% quality cost, because billions of redundant weights average the rounding noise away. → Quantization & the Inference Stack

R

RAG (retrieval-augmented generation) — embed chunks offline, embed the query online, cosine-search for the top chunks, paste them into the prompt, and generate grounded. Every box is a course module. → RAG Internals

Reranking (two-stage retrieval) — a bi-encoder recalls the top ~50 over millions, then a cross-encoder precisely reorders to the top ~5; the highest-ROI, no-retraining RAG upgrade. → Reranking & Retrieval Quality

Recall@k — the fraction of queries whose relevant document appears in the top k results; the single most load-bearing RAG metric (if it's not in the top k, the LLM never sees it). → Evaluating & Tuning Embeddings

Reward hacking — a policy exploiting its reward model's blind spots (sycophancy, padding, gibberish that scores well); the KL leash exists to prevent it. → RLHF & DPO

RLHF — train a reward model from human rankings, then optimize the LLM against it with PPO under a KL penalty to its SFT self; the source of assistant personality. → RLHF & DPO

Residual connection — x + layer(x): each layer adds a correction to a highway whose backward slope is exactly 1, curing vanishing gradients and making depth safe. → Residuals, LayerNorm & FFN

RoPE (rotary position embedding) — rotate Q and K by position-proportional angles so attention depends on relative token distance; the position scheme behind 128k contexts. → Embeddings & Positional Encoding

S

Scaling laws — loss falls as a predictable power law in params/data/compute; the ruler frontier labs budget nine-figure runs with. → Scaling Laws & Chinchilla

SFT (supervised fine-tuning) — training on (instruction, response) pairs with loss on the response; converts a text-continuer into an assistant. → Instruction Tuning (SFT)

SBERT / siamese network — twin encoders with shared weights producing comparable sentence vectors; the architecture that made pre-embedding a corpus (and therefore RAG) possible. → Siamese Networks & SBERT

Span-level F1 — NER's scoreboard: a predicted entity counts only on exact boundary + type match; partial overlap = false positive AND false negative. → NER as Token Classification

Sampling (temperature / top-p) — reshaping the model's output distribution before drawing a token: temperature divides logits (sharp vs flat), top-p keeps the smallest set summing to p. The API dials, demystified. → Sampling: Temperature & Top-p

Self-consistency — sampling N chains of thought and taking the majority answer; independent errors cancel, correct paths converge. Ensemble logic for reasoning. → Reasoning & Test-Time Compute

Speculative decoding — a small draft model proposes tokens, the big model verifies them in one parallel pass; 2–3× faster with mathematically identical output. → Quantization & the Inference Stack

Self-attention — a sentence attending to itself: every token queries every token, updating each vector with weighted context. The bank-problem killer. → Self-Attention: Q, K, V

Seq2seq bottleneck — forcing a whole input through one fixed-size vector between encoder and decoder; its measured failure gave birth to attention. → Seq2Seq & the Bottleneck

Skip-gram — word2vec's flavor where the center word predicts its context words via two embedding matrices and a dot product. → word2vec: Skip-Gram Internals

Softmax — exponentiate-and-normalize: logits → probabilities; temperature is a divisor inside it. → Softmax & Cross-Entropy

Static vs contextual embeddings — one fixed vector per word (word2vec) vs a fresh vector per word per sentence (BERT/MiniLM); the "bank" problem is the divide. → Properties & Limits

Similarity matrix — every pairwise cosine at once (E·Eᵀ): diagonal of 1s, symmetric, topic clusters visible as blocks. The same grid shape underlies attention (M5) and contrastive training (M9). → Dot Product = Similarity

T

Token / tokenization — the subword units models actually read; all context limits and prices are counted in them. ~¾ of an English word each. → Tokenization

Temperature — a divisor applied to logits before softmax: low = sharp/deterministic, high = flat/creative. The API parameter, demystified. → Softmax & Cross-Entropy

Test-time compute — spending more inference tokens (thinking) on hard questions for better answers; a second scaling axis beyond training compute. → Reasoning & Test-Time Compute

Top-p (nucleus sampling) — keep the smallest set of tokens whose probabilities sum to p, then sample; adapts to the model's confidence per token, unlike fixed top-k. → Sampling: Temperature & Top-p

Two-stage retrieval — see Reranking: cheap recall then expensive precision. → Reranking & Retrieval Quality

Transfer learning — borrowed pretrained body + new task head + a freezing dial; why 500 labels can beat 25,000. → Transfer Learning & Heads

V

Vanishing gradient — blame decaying to nothing through long products of small local slopes; the disease that residual connections cure. → Backpropagation, Intuitively

Vector — an ordered list of numbers; equivalently a point or an arrow in space. The universal currency of ML. → Vectors Are Meaning

Z

Zero-shot NER — extracting entity types never seen in training by treating the type name as a query against span embeddings; new type = new string, no annotation, no retraining. → GLiNER's Architecture
