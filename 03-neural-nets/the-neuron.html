The Neuron

Time to build the machine. This module takes you from a single neuron to a trained, evaluated classifier you build yourself — the complete mental toolkit that Modules 4 and 5 assume. The good news: after M1, a neuron contains exactly one new idea. Everything else you already own.

A neuron is a dot product you've already met

Strip the biology metaphor. A neuron takes a vector of inputs, multiplies each input by a learned weight, adds them up, adds a learned bias — and that's M1.2's dot product plus M1.3's bias:

z = w · x + b
In plain words: a weighted opinion poll. Each input gets a learned weight saying "how much do I care about you (and in which direction)"; the bias sets how easy the neuron is to please overall. One number out: the neuron's raw enthusiasm, called the pre-activation or logit.

Why the bend is everything

Recall M1.3's closing interview question: stacking two matrices collapses into one matrix — W₂(W₁x) = (W₂W₁)x. Pure linear layers, no matter how many, can only draw straight decision lines. The activation function — the bend — breaks that collapse. With a bend between layers, composition creates genuinely new shapes: curves, corners, islands. Depth only means something because of the bend.

Meet the bends: sigmoid, tanh, ReLU, GELU

Sigmoid squashes any number into (0, 1) — an S-curve. Historically everywhere; today mostly at output time for probabilities (it's the σ from negative sampling!). Its flaw: for large |z| it's nearly flat, so gradients through it vanish (M1.4's chain-of-slopes multiplying by ≈0 — full consequences in 3.4). Tanh: same S-shape, range (−1, 1), zero-centered, same flatness flaw.

ReLU — max(0, z) — was the great simplification: pass positives unchanged, zero out negatives. Cheap, and its slope is exactly 1 for all positive z, so gradients survive deep stacks. Cost: "dead" neurons stuck at 0. GELU, the transformer-era default (used by BERT, GPT, and inside MiniLM), is a smoothed ReLU: no hard corner, slightly negative dip near zero, better training dynamics at scale. Practical hierarchy: ReLU = the workhorse idea, GELU = the polished version transformers actually ship with.

Layer, width, depth — the vocabulary assembled

Stack n neurons side by side, feed them the same input vector: their n weight-rows form exactly M1.3's matrix, and the layer computes activation(Wx + b) — matrix multiply, add bias, bend. Width = neurons per layer (the "hidden size": 384 in MiniLM, 12,288 in GPT-3). Depth = number of layers (6 in MiniLM-L6, 96 in GPT-3). Width buys parallel pattern detectors per step; depth buys composition — patterns of patterns of patterns. Transformers, as you'll see, are wide and deep, plus one extra trick (attention) that lets positions talk to each other.

Real numbers

GELU vs ReLU on actual values: ReLU(−0.5) = 0, GELU(−0.5) ≈ −0.154; ReLU(0.5) = 0.5, GELU(0.5) ≈ 0.345; by z = 3 they agree (GELU(3) ≈ 2.996). The difference is only near zero — a soft transition instead of a corner — yet at 100M+ parameter scale that smoothness measurably improves training. MiniLM's config.json says "hidden_act": "gelu": a field you can now read.

Connect the dots

Two flashbacks. (1) word2vec (M2.2) had no activation function — lookup, dot, done. That's why it's called a shallow method: no bends, no composition, just geometry. The leap from word2vec to BERT is, in large part, adding depth-with-bends on top of the same embedding table. (2) Your GLiNER and MiniLM models contain "feed-forward" blocks (M5.5) that are literally this page: Linear → GELU → Linear. About two-thirds of MiniLM's compute is neurons doing exactly what this page's first animation showed.

Build: a neuron in numpy, and the collapse, verified
import numpy as np

x = np.array([2.0, -1.0, 0.5])
w = np.array([0.9, 0.1, -0.6])
b = 0.2
z = w @ x + b                      # the whole neuron: one line
print("z =", z)                    # 1.6 — matches the animation

relu = lambda v: np.maximum(0, v)

# --- prove the collapse ---
rng = np.random.default_rng(0)
W1, W2 = rng.normal(size=(4, 3)), rng.normal(size=(2, 4))
xs = rng.normal(size=(3, 100))

deep_linear = W2 @ (W1 @ xs)          # two linear layers
collapsed   = (W2 @ W1) @ xs          # one merged matrix
print(np.allclose(deep_linear, collapsed))   # True — depth was fake

deep_bent = W2 @ relu(W1 @ xs)        # add one bend
print(np.allclose(deep_bent, collapsed))     # False — depth is now real

That pair of True/False lines is the deepest fact on this page, verified in milliseconds. Keep this script — 3.7 grows it into a full trained classifier.

If you remember one thing

Neuron = dot product + bias + bend. The bend is the only new idea — and it's load-bearing: without it, a thousand layers equal one. Layers are matrices of neurons; width is neurons-per-layer, depth is layers; and the GELU inside every transformer you use is this page's bend, smoothed for scale.

Interview questions

Why do neural networks need nonlinear activation functions?

Because compositions of linear maps are linear: W₂(W₁x) = (W₂W₁)x, so any depth of pure-linear layers collapses to a single matrix and can only represent linear functions (straight decision boundaries). A nonlinearity between layers prevents the collapse, making each added layer genuinely increase expressive power — with enough width/depth, networks with nonlinearities are universal function approximators.

Compare sigmoid, ReLU and GELU. Why did transformers pick GELU?

Sigmoid: squashes to (0,1), saturates at both ends → vanishing gradients in deep nets; now mainly used for output probabilities. ReLU: max(0,z), cheap, gradient exactly 1 for positive inputs → trains deep networks well, but neurons can "die" at 0. GELU: a smooth, probabilistic relaxation of ReLU (slight negative dip, no corner) with better-behaved gradients near zero — empirically more stable/performant at transformer scale, which is why BERT/GPT/MiniLM use it. Differences are small per-neuron and compound over hundreds of millions of parameters.

What exactly is a "logit"?

The raw pre-activation score z = w·x + b before any squashing into probabilities. In classification, the final layer outputs one logit per class; softmax (next page) converts them to probabilities. When APIs expose "logprobs" or when papers say "logit lens", they're referring to these raw scores — knowing the term precisely is a cheap credibility win.

Width vs depth — what does each buy you?

Width (neurons per layer) buys parallel feature detectors at the same level of abstraction — more patterns noticed per step. Depth (layers) buys composition — later layers build features of features, enabling hierarchical abstraction (edges→shapes→objects; tokens→phrases→semantics). Empirically both matter and are scaled together (M7's scaling laws); depth without nonlinearity is worthless, and extreme depth without tricks (residuals, M5.5) is untrainable.

A single neuron with a sigmoid — what classic model is that?

Logistic regression: σ(w·x + b) is exactly its form. A neural network is logistic-regression-like units stacked and composed with nonlinearities — useful framing both for interviews and for intuition: you already understood the atom; networks are the chemistry.
