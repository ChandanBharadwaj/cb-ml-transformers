Residuals, LayerNorm & FFN

Attention gets the fame; this page covers the three unglamorous parts that make it trainable and powerful: the skip connections that let 100-layer models learn at all, the normalization that keeps activations sane, and the feed-forward network that — surprise — holds two-thirds of the parameters and most of the model's factual knowledge. Skipping this page is how people end up knowing attention but not transformers.

Residual connections: the gradient highway

M3.4 left a cliffhanger: blame shrinks through long products of local slopes, so deep stacks starve their early layers. The fix that changed everything (ResNet 2015, adopted by transformers 2017): don't replace the input with the layer's output — add the output to it. x_new = x + layer(x). Each layer computes a correction, not a replacement.

A useful way to think about the whole model, popular in interpretability work: the highway is a residual stream — a running 384-dim workspace per token — and every attention head and FFN reads from it and writes small updates into it. Twelve stops later (or 96), the workspace holds the answer.

LayerNorm: keep every token's vector in a standard range

With hundreds of additions into the stream, magnitudes drift — some vectors blow up, some shrink, and downstream layers (whose weights expect a certain input scale) destabilize. LayerNorm is the thermostat: for each token's vector independently, subtract its mean, divide by its standard deviation (re-centering it to mean 0, spread 1), then apply a learned per-dimension scale and shift (γ, β) so the network can still choose its preferred range. Placement detail with a name worth knowing: modern models put it before each sublayer ("pre-LN") rather than after ("post-LN", the 2017 original) — pre-LN trains far more stably and is why current LLMs don't need the delicate warmup rituals early transformers did.

The FFN: where most of the model actually lives

After attention mixes information across tokens, each token visits the feed-forward network — the same two-layer M3.1 network, applied to every position independently: expand 384 → 1536 (4×), GELU bend, compress back 1536 → 384. No token-to-token communication at all. Attention gathers; the FFN processes what was gathered.

Real numbers: MiniLM's parameter budget, audited

Per layer: attention (W_Q, W_K, W_V, W_O = 4 × 384×384 + biases) ≈ 0.59M; FFN (384×1536 + 1536×384 + biases) ≈ 1.18M — the FFN is 2× the attention, exactly the 4×-expansion arithmetic. LayerNorms: a rounding error (~1.5k/layer). Whole model: embeddings ≈ 11.9M (52%) · FFNs ≈ 7.1M (31%) · attention ≈ 3.5M (16%) · norms <1%. In big LLMs (embeddings amortized away) the steady-state split is ≈ ⅓ attention, ⅔ FFN — "attention is all you need" was a great title and a slight exaggeration.

Connect the dots

Three callbacks close here: M1.3's identity matrix (residuals make near-identity the default), M3.4's vanishing gradients (the highway is the cure — you can now explain why 96-layer models train), and M3.1's expand-bend-compress neuron (the FFN is it, industrial-sized). Forward pointer for your wallet: because FFNs hold ⅔ of parameters, they're the prime target for LoRA adapters (M8.5) and quantization (M11.3) — most of what you compress or adapt in practice is this page's block.

Build: residual rescue + LayerNorm, verified in numpy
import numpy as np
rng = np.random.default_rng(0)

# --- residuals rescue deep gradients (M3.4's experiment, upgraded) ---
def deep_grad(n_layers, residual):
    x = rng.normal(size=16); grad = np.ones(16)
    slopes = []
    for _ in range(n_layers):
        W = rng.normal(size=(16, 16)) * 0.25          # smallish weights
        local = W.T                                    # layer's slope (linear)
        slopes.append(local + (np.eye(16) if residual else 0))  # +I = the highway!
    for S in reversed(slopes):
        grad = S @ grad
    return np.abs(grad).mean()

print("plain 20 layers    :", f"{deep_grad(20, False):.2e}")   # ~vanished
print("residual 20 layers :", f"{deep_grad(20, True):.2e}")    # healthy ≈ 1

# --- LayerNorm in 4 lines ---
def layernorm(x, gamma=1.0, beta=0.0, eps=1e-5):
    return gamma * (x - x.mean()) / np.sqrt(x.var() + eps) + beta

wild = np.array([300.0, -50.0, 7.0, 0.001, 120.0])
print("before:", wild, "\nafter :", layernorm(wild).round(2))  # tamed

The two printed gradient magnitudes are this page's whole argument in two numbers: the +I of the residual keeps the backward product near 1 while the plain stack decays to ~10⁻¹². That's the difference between "deep learning" and "shallow learning with ambitions."

A transformer layer is attention (mix across tokens) + FFN (think per token), each wrapped in residual + (gradient highway, identity default) and LayerNorm (per-token thermostat). Interview questions

Why are residual connections essential in transformers?

Two reasons. Training: the addition node's gradient is exactly 1, so backprop has an unattenuated path to every layer — the vanishing-gradient product of deep stacks is bypassed (a 96-layer GPT is untrainable without them). Representation: layers learn corrections to an identity default rather than full transformations, so useless layers can no-op harmlessly and depth becomes monotonically safe to add. The "residual stream" framing — layers reading/writing a shared per-token workspace — is also the backbone of modern interpretability.

LayerNorm vs BatchNorm — why do transformers use LayerNorm?

BatchNorm normalizes each feature across the batch — statistics depend on batchmates, which is awkward for variable-length sequences, small/streaming batches, and autoregressive inference (batch of 1). LayerNorm normalizes across features within each single token's vector — batch-independent, identical behavior train vs inference, well-defined per position. Bonus detail: pre-LN (normalize before each sublayer) vs post-LN (after, the 2017 original) — pre-LN yields far more stable training and is the modern default.

What does the FFN do that attention can't, and why expand 4×?

Attention only computes weighted averages of value vectors — mixing existing information across positions; it can't apply arbitrary nonlinear transformations to content. The FFN provides that: per-token expand→GELU→compress, where the 4× widening gives high-dimensional scratch space for many intermediate features before re-projecting. Division of labor: attention routes, FFN computes. Evidence localizes most factual recall in FFN layers (key–value memory behavior), which is why FFNs get ⅔ of the parameter budget.

Where do a transformer's parameters actually sit, proportionally?

Per layer, with the standard 4× FFN: attention ≈ 4d² (Q,K,V,O), FFN ≈ 8d² — a 1:2 split, so ~⅓ attention / ~⅔ FFN in the stack. Small models add a big embedding-table share (52% of MiniLM); large models amortize it (~6% of Llama-3-8B). Practical corollaries: FFNs dominate quantization/adapter targets, and "attention is the expensive part" is true of compute at long context (O(n²)), not of parameters.

A 20-layer MLP without residuals fails to train; with them it works. Explain to a junior engineer.

Gradients reach early layers as a product of 20 per-layer slopes; if each averages 0.5, the signal arrives at 0.5²⁰ ≈ one-millionth — those layers effectively never learn. A residual connection adds the input straight to the output, and the derivative of that addition is 1, giving blame a decay-free path backward. Result: every layer hears the loss clearly regardless of depth. Then show them this page's 10-line numpy demo — the two printed numbers end the argument.
